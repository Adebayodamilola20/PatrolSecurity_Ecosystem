# ⚡ Neurons — Rules

Every **task or conversation** handled by any AI becomes ONE neuron note here.
This is what makes the [[AI_BRAIN]] graph "spike" — each neuron is a node that
links back to the core, so the network grows visibly as the team works.

## Rules (all agents)
1. **One neuron per task/conversation.** Create it when you start real work.
2. **Unique file name:** `YYYYMMDD-HHMM-<agent>-<slug>.md`
   e.g. `20260630-1430-claude-webapp-scaffold.md`
3. **Give it a memorable codename** in the `codename:` field (unique, fun) so humans can refer to it — e.g. "Project Lighthouse".
4. **Always link `[[AI_BRAIN]]`** so it connects to the core hub.
5. **Link the agent** ([[Claude_Code]], etc.) and [[Current_Task]].
6. **Keep it short** — what/why/result/next. No large code; link `path:line` instead.
7. Mark `status:` `active` → `done` when finished.

Copy [[_Neuron_Template]] to start a new one.
